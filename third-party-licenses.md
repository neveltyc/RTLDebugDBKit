# Third-party licences

`rtl-designdb` ships as a single statically linked binary, so a downloaded
release asset carries no repository around it. The notices its dependencies
require in a binary redistribution are collected here, and this file is
published with every release.

The exporter's own code is BSD-3-Clause; see [LICENSE](LICENSE).

| Component | Licence | Linked into the binary |
|---|---|---|
| [slang](https://github.com/MikePopoloski/slang) | MIT | yes — the SystemVerilog front end |
| [mimalloc](https://github.com/microsoft/mimalloc) | MIT | yes — pulled in by slang |
| [BS::thread_pool](https://github.com/bshoshany/thread-pool) | MIT | yes — vendored in slang's `external/` |
| [Boost.Unordered / Boost.Concurrent](https://www.boost.org/) | BSL-1.0 | yes — vendored in slang's `external/` |
| [nonstd::expected](https://github.com/martinmoene/expected-lite) | BSL-1.0 | yes — vendored in slang's `external/` |
| [SQLite](https://sqlite.org/) | public domain | yes — the official amalgamation |

SQLite is dedicated to the public domain by its authors and imposes no
redistribution condition. The others are reproduced below.
